
# 🧮 CLASSNOTE

### Calculadora matemática paso a paso

CLASSNOTE es una aplicación web desarrollada en Python que permite resolver operaciones matemáticas y conocer sus procedimientos.

## Funcionalidades

- Operaciones básicas.
- Multiplicación implícita.
- Potenciación.
- Radicación.
- Porcentajes.
- Promedios.
- Valor absoluto.
- Comparaciones matemáticas.
- Operaciones lógicas.
- Procedimientos matemáticos detallados.
- Historial de operaciones.

## Tecnologías

- Python 3
- Streamlit
- GitHub

## Diseño

Azul, azul oscuro y amarillo.

## Autor

Angel

## Objetivo

Facilitar el aprendizaje matemático mediante una calculadora interactiva que explica los procedimientos de cada operación.
